# Capstone Project: Frontend Web Application

A modern frontend web application built as a capstone project.

## Overview
This project is an interactive single-page web application providing a responsive and accessible user experience.

## Getting Started
Instructions for setting up the project locally.

### Prerequisites
- Node.js (v18 or higher)
- npm or pnpm

### Installation
```bash
npm install
```

### Development
```bash
npm run dev
```

### Build
```bash
npm run build
```
